# MikroTik Beacon Manager

> Source: https://manual.mikrotik.com/docs/internet-of-things/bluetooth/mikrotik-beacon-manager
>
> MikroTik Beacon Manager app for configuring TG-BT5 series Bluetooth tags, with guides for Android and iOS and tag advertisement formats.

MikroTik Beacon Manager is an app that should be used to configure TG-BT5-XX Bluetooth tags.
