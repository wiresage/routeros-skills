# /tool/traffic-generator/packet-template

> Source: https://manual.mikrotik.com/docs/cli-reference/tool/traffic-generator/packet-template

Type: Directory

**Arguments**

- `name` (string)
- `header-stack` (multi { header: enum (mac | vlan | ip | udp | raw | ipv6 | tcp) })
- `port` (enum)
- `interface` (iface_enum)
- `mac-src` (multi { array-id, array-id, mac-mask: composite { mac: macAddr , mask: [ macAddr] } })
- `mac-dst` (multi { array-id, array-id, mac-mask: composite { mac: macAddr , mask: [ macAddr] } })
- `mac-protocol` (multi { protocol: alt { protocol-name: enum () , protocol-number: num [ .. 65535] } })
- `vlan-priority` (multi { priority: num [ .. 7] })
- `vlan-id` (multi { id: num [ .. 4095] })
- `vlan-protocol` (multi { protocol: alt { protocol-name: enum () , protocol-number: num [ .. 65535] } })
- `ip-dscp` (multi { dscp: num [ .. 255] })
- `ip-id` (multi { id: num [ .. 65535] })
- `ip-frag-off` (multi { frag-off: num [ .. 65535] })
- `ip-ttl` (multi { ttl: num [ .. 255] })
- `ip-src` (multi { array-id, array-id, ip-range: ipRange })
- `ip-dst` (multi { array-id, array-id, ip-range: ipRange })
- `ip-protocol` (multi { protocol-name: enum () })
- `ip-gateway` (ipAddr)
- `udp-src-port` (multi { array-id, array-id, port-range: range [ .. 65535] })
- `udp-dst-port` (multi { array-id, array-id, port-range: range [ .. 65535] })
- `udp-checksum` (multi { array-id, checksum: num [ .. 65535] })
- `raw-header` (multi { raw-header: string })
- `ipv6-src` (multi { array-id, array-id, ipv6-mask: ip6Prefix })
- `ipv6-dst` (multi { array-id, array-id, ipv6-mask: ip6Prefix })
- `ipv6-next-header` (multi { protocol: enum () })
- `ipv6-gateway` (ip6Addr)
- `ipv6-traffic-class` (multi { traffic-class: num [ .. 255] })
- `ipv6-flow-label` (multi { flow-label: num [ .. 0xfffff] })
- `ipv6-hop-limit` (multi { hop-limit: num [ .. 255] })
- `tcp-src-port` (multi { array-id, array-id, port-range: range [ .. 65535] })
- `tcp-dst-port` (multi { array-id, array-id, port-range: range [ .. 65535] })
- `tcp-syn` (multi { array-id, array-id, syn-range: range })
- `tcp-ack` (multi { array-id, array-id, ack-range: range })
- `tcp-data-offset` (multi { data-offset: num [ .. 15] })
- `tcp-flags` (multi { flags: ubit (fin, syn, rst, psh, ack, urg, ece, cwr, ns, res0, res1, res2) })
- `tcp-window-size` (multi { window-size: num [ .. 65535] })
- `tcp-urgent-pointer` (multi { urgent-pointer: num [ .. 65535] })
- `data` (enum: uninitialized | random | specific-byte | incrementing)
- `data-byte` (num)
- `random-byte-offsets-and-masks` (multi { array-id, array-id, offset-and-mask: composite { offset: num [ .. 256] , mask: num [ .. 255] } })
- `random-ranges` (object { random-range: super { offset: num [ .. 256] , [width] :enum (8 | 16 | 32) , [range] :range } })
- `special-footer` (bool)
- `compute-checksum-from-offset` (num)
