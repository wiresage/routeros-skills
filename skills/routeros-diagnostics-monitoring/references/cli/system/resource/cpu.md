# /system/resource/cpu

> Source: https://manual.mikrotik.com/docs/cli-reference/system/resource/cpu

Type: Directory

Per-CPU usage breakdown of the system resource counters.

**Read-only arguments**

- `cpu` (string): Identification number of the CPU whose usage is shown
- `load` (num): CPU usage in percent
- `irq` (num): IRQ usage in percent
- `disk` (num): Disk usage in percent
