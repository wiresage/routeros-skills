# How to install WinBox

> Source: https://help.mikrotik.com/docs/spaces/RKB/pages/6488069/How+to+install+WinBox
>
> Only on help.mikrotik.com: the manual has no equivalent page. The help site is frozen; this page was last edited 2024-11-04.

Winbox is a small utility that allows the administration of MikroTik RouterOS using a fast and simple GUI.

## Step-by-step guide

In order to install WinBox:

1. Go to <https://mikrotik.com/download>;
2. Choose your preferred WinBox;
3. Save to your hard drive;
4. Open application.
