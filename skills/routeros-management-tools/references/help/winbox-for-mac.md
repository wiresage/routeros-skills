# Winbox for mac

> Source: https://help.mikrotik.com/docs/spaces/RKB/pages/6488074/Winbox+for+mac
>
> Only on help.mikrotik.com: the manual has no equivalent page. The help site is frozen; this page was last edited 2021-09-06.

It is possible to run Winbox on macOS and Linux by using [Wine](https://dl.winehq.org/wine-builds/macosx/download.html) software. You are also free to use the Web interface that is enabled by default, just enter the IP address of your MikroTik device in your preferred web browser.

If you do wish to specifically use Winbox on your Apple computer, you can follow more detailed macOS setup instructions in the [Winbox documentation](https://help.mikrotik.com/docs/display/ROS/Winbox#Winbox-RunWinboxonmacOS) page, these steps are are also shown in [this video](https://www.youtube.com/watch?v=FXhT2QGxgp0).
