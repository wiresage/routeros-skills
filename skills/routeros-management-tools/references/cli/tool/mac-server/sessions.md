# /tool/mac-server/sessions

> Source: https://manual.mikrotik.com/docs/cli-reference/tool/mac-server/sessions

Type: Directory

Open MAC Telnet sessions to this router. MAC WinBox connections are not listed. For examples, see [MAC server](../../../guides/management-tools/mac-server.md).

**Arguments**

- `interface` (iface_enum): Interface the session arrived on.
- `src-address` (macAddr): MAC address of the client.
- `uptime` (time): How long the session has been open.
