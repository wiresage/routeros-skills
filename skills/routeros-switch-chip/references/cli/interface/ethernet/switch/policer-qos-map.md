# /interface/ethernet/switch/policer-qos-map

> Source: https://manual.mikrotik.com/docs/cli-reference/interface/ethernet/switch/policer-qos-map

Syscap: musicswitch; Type: Directory

**Flags**

- `I`: invalid

**Arguments**

- `dscp-for-yellow` (num): Policer DSCP remapping value for yellow packets.
- `pcp-for-yellow` (num): Policer PCP remapping value for yellow packets.
- `dei-for-yellow` (num): Policer DEI remapping value for yellow packets.
- `dscp-for-red` (num): Policer DSCP remapping value for red packets.
- `pcp-for-red` (num): Policer PCP remapping value for red packets.
- `dei-for-red` (num): Policer DEI remapping value for red packets.

**Read-only arguments**

- `priority` (num)
