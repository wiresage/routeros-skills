# /interface/w60g

> Source: https://manual.mikrotik.com/docs/cli-reference/interface/w60g

Syscap: 60ghz; Package: wireless-rep; Type: Directory

**Flags**

- `X`: disabled
- `R`: running

**Arguments**

- `name` (string)
- `mtu` (num)
- `l2mtu` (num)
- `mac-address` (macAddr)
- `arp` (enum: disabled | enabled | proxy-arp | reply-only | local-proxy-arp)
- `arp-timeout` (alt { arp-timeout: enum (auto) , arp-timeout: time })
- `region` (enum: no-region-set | usa | canada | asia | eu | japan | australia | china)
- `mode` (enum: ap-bridge | station-bridge | sniff | bridge)
- `ssid` (string)
- `frequency` (enum: auto | 58320 | 60480 | 62640 | 64800 | 66000 | 66960)
- `scan-list` (multi { array-id, frequency: enum (58320 | 60480 | 62640 | 64800 | 66000 | 66960) })
- `password` (string)
- `tx-sector` (num)
- `put-stations-in-bridge` (iface_enum)
- `isolate-stations` (bool)
- `mdmg-fix` (bool)

**Read-only arguments**

- `default-name` (string)
- `default-scan-list` (multi { array-id, frequency: enum (58320 | 60480 | 62640 | 64800 | 66000 | 66960 | 69120) })
- `beamforming-event` (num)
- `tx-io-msdu` (num)
- `tx-sw-msdu` (num)
- `tx-fw-msdu` (num)
- `tx-ppdu` (num)
- `tx-ppdu-from-q` (num)
- `tx-mpdu-new` (num)
- `tx-mpdu-total` (num)
- `tx-mpdu-retry` (num)
- `rx-ppdu` (num)
- `rx-mpdu-crc-err` (num)
- `rx-mpdu-crc-ok` (num)
