# /interface/wifi/security/multi-passphrase

> Source: https://manual.mikrotik.com/docs/cli-reference/interface/wifi/security/multi-passphrase

Type: Directory

**Flags**

- `X`: disabled
- `E`: expired

**Arguments**

- `group` (string; mandatory)
- `passphrase` (string; mandatory)
- `vlan-id` (num; unset)
- `expires` (date; unset)
- `isolation` (bool; unset)
