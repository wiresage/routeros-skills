# /ip/ipsec/policy/group

> Source: https://manual.mikrotik.com/docs/cli-reference/ip/ipsec/policy/group

Type: Directory

This menu allows you to create additional policy groups used by policy templates.

**Flags**

- `*` (default): Whether the item is the default.

**Arguments**

- `name` (string; mandatory): Group name.
- `interface` (iface_enum): Interface to which policies in this group apply.
