# /routing/table

> Source: https://manual.mikrotik.com/docs/cli-reference/routing/table

Type: Directory

**Flags**

- `D`: dynamic
- `X`: disabled
- `I`: invalid
- `U`: used

**Arguments**

- `name` (string): Name of the routing table.
- `fib` (switch; unset): Flag indicating whether routes in this table will be installed in the [FIB](../../guides/user-guides/routing-and-networking-protocols/routing-decision.md#forwarding-information-base).
