# LTE USB modem

> Source: https://help.mikrotik.com/docs/spaces/RKB/pages/8323170/LTE+USB+modem
>
> Only on help.mikrotik.com: the manual has no equivalent page. The help site is frozen; this page was last edited 2019-12-05.

## Problem

Are there any USB LTE modems available for the MikroTik devices with a USB port so we can plug into our existing units on-premise and use mobile data?

## Solution

Currently, we do not have any USB modems in our product range. It is possible to use a mini-PCIe to USB adapter to connect our LTE modem to a USB port on the device. List of our LTE mini-PCIe factor modems:
<https://mikrotik.com/product/r11e_lte_us>
<https://mikrotik.com/product/r11e_lte>
<https://mikrotik.com/product/r11e_4g>
<https://mikrotik.com/product/r11e_lte6>

Alternative is to use a USB modem from the supported peripherals list:
<https://wiki.mikrotik.com/wiki/Manual:Peripherals>
