# /console/settings

> Source: https://manual.mikrotik.com/docs/cli-reference/console/settings

Type: Settings Directory

**Arguments**

- `sanitize-names` (bool): Replace reserved characters (\\ / : * ? |) with underscores in file and script names.
- `log-script-errors` (bool): write background script failures to log
- `tab-width` (num): default tab width in fullscreen editor
