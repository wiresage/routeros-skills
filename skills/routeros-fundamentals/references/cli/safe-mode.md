# /safe-mode

> Source: https://manual.mikrotik.com/docs/cli-reference/safe-mode

Type: Settings Directory

**Read-only arguments**

- `enabled` (bool): indicates if safe mode is enabled
- `user` (string): user name of the current safe mode session
- `current` (bool): indicates if safe mode is enabled for the current session
- `owner` (string): safe mode session owner
