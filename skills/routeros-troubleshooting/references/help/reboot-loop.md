# Reboot loop

> Source: https://help.mikrotik.com/docs/spaces/RKB/pages/8323160/Reboot+loop
>
> Only on help.mikrotik.com: the manual has no equivalent page. The help site is frozen; this page was last edited 2019-12-05.

## Problem

The device reboots continuously.

## Follow these steps to load the backup bootloader:

1. Press and hold the reset button;
2. Plug the device into the power source;
3. You need to hold reset button just for 1-2 seconds and the backup bootloader will be loaded;
4. When the device has loaded open the CLI and execute the command to upgrade your bootloader "/system routerboard upgrade"
