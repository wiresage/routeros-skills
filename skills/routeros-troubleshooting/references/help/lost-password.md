# Lost password

> Source: https://help.mikrotik.com/docs/spaces/RKB/pages/8323179/Lost+password
>
> Only on help.mikrotik.com: the manual has no equivalent page. The help site is frozen; this page was last edited 2020-01-30.

# Problem

*[Figure]*

RouterOS login is not working because of a lost or forgotten password.

# Solution

The only solution to recover the device is by resetting it to factory defaults.

> **Warning**
>
> All the unit configuration will be lost!

Please be sure, you save configuration "/export" or device backup at a separate place.

# Be Aware

> **Warning**
>
> If someone offers you "password recovery" tools, be aware, most likely it is a scam! Because in reality there are no such tools!
