# /system/history

> Source: https://manual.mikrotik.com/docs/cli-reference/system/history

Type: Directory

**Flags**

- `U`: undoable
- `R`: redoable
- `F`: floating-undo

**Read-only arguments**

- `redo` (cfg)
- `undo` (cfg)
- `action` (string)
- `by` (string)
- `policy` (multi { array-id, policy: enum })
- `time` (date)
- `trace` (string)
