**First steps:**

- Download the latest SwitchOS software version from [https://mikrotik.com/download;](https://mikrotik.com/download)
- Connect your computer to any of the Ethernet ports;
- Connect the device to the power source;
- Set an IP address of your computer to 192.168.88.2;
- Open your Web browser, the default management IP address is 192.168.88.1, with the username *admin* and no password (or, for some models, check user passwords on the sticker);
- Upload file with the web browser to the Upgrade tab, the device will reboot after an upgrade;
- Set up your password to secure the device.
