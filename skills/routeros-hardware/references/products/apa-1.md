## Powering

- Number of DC inputs 1 (3-pin terminal);
- Min voltage 12 V;
- Max voltage 48 V;
- Max power consumption with attachment 100 W.

## Installation

Input and output connection scheme:

- GND - Negative terminal DC.
- IN - Positive terminal DC.
- EN - Enable voltage down converter:High (9-60VDC) = on, Low(0-1.2VDC) = off,Can be used with vehicle ignition to enable a voltage converter, by default jumper enables a **voltage-down** converter.

*[Figure]*

- PASS - pass-through mode - input voltage after protection circuit, EN input does not affect PASS output. OUT and PASS outputs can be used simultaneously, but the 3A input fuse limits the current, so the output power budget depends on the input voltage level.
