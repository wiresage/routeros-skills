## Powering

The unit accepts power from an AC source:

Input: 100-240V ~ 50/60Hz.

*[Figure]*

Output:

|  |  |
| --- | --- |
| DC output voltage (V) | 12 |
| DC output current (A) | 5 |
| DC output power (W) | 60 |

## Installation

- Push blue anchor to the right side and pull out old PSU:

*[Figure]*

- Install replacement unit by inserting into position and pushing in until blue anchor locks.
  The PSU can be replaced while the device is operating.
